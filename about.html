About Glow-Grid

Glow-Grid is a free daily puzzle game inspired by Lights Out. Light up all 25 cells of the grid. Every day brings a new puzzle, and every puzzle has a solution.

Play today's puzzle

How to play

  1. Tap any cell to toggle it and its neighbors.
  2. If the cell you tap is ON, it flips the cells next to it in a + pattern (up, down, left, right).
  3. If the cell you tap is OFF, it flips the cells next to it in a × pattern (the four diagonals).
  4. Light up all 25 cells to win.
  5. Try to find the shortest path. Fewer moves is better.

Daily puzzle

The puzzle is created from the date, so everyone gets the same grid on the same day. Each puzzle starts from a solved grid and is scrambled with random moves. This is why it can always be solved. You can also go back to play older puzzles and keep a daily streak.

Features

  • A new puzzle every day, with a streak counter
  • Each cell plays a note, so your solution makes a melody
  • Song challenges
  • Hints when you are close to solving
  • Replay of your solution, a heatmap of your taps, and sharing
  • Works on phone and desktop, and offline after the first visit

Open source

Glow-Grid is a single HTML file with no frameworks and no build step. The code is free to read on GitHub.
