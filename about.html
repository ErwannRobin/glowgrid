About Glow-Grid

Light them all

Glow-Grid is a free daily puzzle game inspired by Lights Out. Light up all 25 cells of the grid. Every day brings a new puzzle, and every puzzle has a solution.

Play today's puzzle

How to play

Tap a cell to flip it and some of its neighbors. What happens depends on the cell you tap:

ON cell → + pattern Flips the cell and up, down, left, right.
OFF cell → × pattern Flips the cell and its four diagonals.
  1. Light up all 25 cells to win.
  2. Cells on the edge have fewer neighbors. Those are ignored.
  3. Try to find the shortest path. Fewer moves is better.

Try it here

This is a small demo with the same rules. Tap the cells and listen. Each cell has its own note.

Daily puzzle

The puzzle is created from the date, so everyone gets the same grid on the same day. Each puzzle starts from a solved grid and is scrambled with random moves. This is why it can always be solved.

You can go back to play older puzzles, and keep a daily streak.

Features

Tap a card to hear its note.

Open source

Glow-Grid is a single HTML file with no frameworks and no build step. All sounds are made live in your browser with the Web Audio API. The code is free to read on GitHub.
